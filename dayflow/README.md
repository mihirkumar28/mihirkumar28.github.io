# DayFlow

A mobile-first daily timetable and time-blocking PWA.

## Features

- Daily time blocks with live current/next state
- Done, skip, undo, and progress tracking
- Fixed / important / flexible / optional priorities
- WFH, office, and weekend templates
- Recovery mode for late starts
- Browser-local persistence
- Installable PWA with offline caching
